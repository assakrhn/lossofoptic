# FTTH Loss Challenge

Web kuis individual untuk pembelajaran Link Budget FTTH.

## Struktur
- Level 1: matching jenis loss. Siswa boleh mencoba berulang; sistem mencatat percobaan sampai semua pasangan benar.
- Level 2: 3 soal acak dari 10 soal jarak bilangan genap + 1 soal acak dari 3 soal jarak desimal.
- Level 3: menghitung konektor pada gambar OLS–OTB–Closure–OTB–OPM. Gambar berasal dari pengguna.
- Level 4: 1 soal acak dari 3 soal splitter + OLT.
- Final Challenge: menghitung Rx power.
- Result Card: satu halaman hasil untuk screenshot guru.

## GitHub Pages
1. Upload seluruh isi folder ini ke repository GitHub.
2. Pastikan `index.html` berada di root repository.
3. GitHub → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder `/root`.
6. Save.
7. Buka URL GitHub Pages yang diberikan GitHub.

Web ini tidak memakai library eksternal, sehingga dapat dijalankan offline setelah folder diunduh.
